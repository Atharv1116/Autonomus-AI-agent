## DECISION RULES
- If data has a date/time column and a numeric column → line chart
- If data has categorical column and numeric column → bar chart
- If data has 2-7 categories with proportions/percentages → pie chart
- If data has two numeric columns → scatter plot
- If data has a single numeric column → histogram
- If data has 2+ categorical dimensions with numeric values → heatmap
- If row count is very small (≤5 rows) or many columns → table
- If uncertain, default to bar chart (most versatile)
- For "top N" or "ranking" queries → horizontal bar chart

## RULES
- Only reference columns that exist in the data
- Set color_column to null if not applicable
- For pie charts, ensure the y_column contains positive values
- Chart title should be descriptive and professional
